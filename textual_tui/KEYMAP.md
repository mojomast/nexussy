# Textual TUI Keymap

| Key | Action |
|---|---|
| `Tab` / `Shift+Tab` | Move focus in visual order |
| `Arrows` / `h j k l` | Move stages or focused lists |
| `Enter` | Activate focused control or send composer |
| `Esc` | Close overlay, exit stage chat, return focus |
| `Ctrl+P` | Command palette entry point |
| `?` | Help screen |
| `c` | Open selected stage chat |
| `a` | Show artifacts inspector |
| `w` | Show workers inspector |
| `l` | Show logs/transcript |
| `r` | Routing/settings screen |
| `d` | Diagnostics inspector |
| `p` | Pause selected stage |
| `u` | Resume selected stage |
| `x` | Cancel selected stage/run |
| `s` | Skip selected stage |
| `y` | Advance pending gate |
| `n` | Stay paused at gate |

All primary actions are also visible as buttons or panels. The shortcut footer is supplemental, not the only path.
